# 이전 단일 모터 인터록 계획: 현재 상태

이 문서는 초기의 ADXL345·단일 진동모터·ESD_SIM 인터록 방향을 기록한 것입니다. 현재 프로젝트의 실제 구현 방향은 **BNO085 UART-RVC + RV32I CPU + R0/R1/R2 서보를 이용한 3축 짐벌 제어 MVP**로 전환되었습니다.

현재 기준의 배선, 핀맵, MMIO, 빌드 명령, 검증 범위는 아래 문서를 사용합니다.

- [BNO085 + RV32I 3축 짐벌 구현 가이드](BNO085_RISCV_3AXIS_GIMBAL_KO.md)

진동/FDC는 3축 기구와 BNO085 로그가 안정적으로 동작한 다음 단계에서 PC의 SPC 및 Isolation Forest 경고로 확장합니다. 실제 ESD/스파크 생성은 프로젝트 범위에 포함하지 않습니다.
